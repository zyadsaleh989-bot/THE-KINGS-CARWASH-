THE KINGS — FIXED IMAGE LOADING

This archive contains the actual website files, not just the HTML.

OPTION A — Cloudflare Pages Direct Upload:
1. Extract this ZIP on your computer.
2. In Cloudflare Pages > Upload assets, upload the CONTENTS of the extracted folder, or upload this ZIP directly if offered.
3. Confirm that index.html is at the root of the deployed files.
4. Confirm the assets folder is next to index.html.

OPTION B — Cloudflare Pages connected to GitHub:
1. Push ALL files in this folder to the ROOT of the GitHub repository.
2. Framework preset: None
3. Build command: exit 0 (or leave blank if supported)
4. Build output directory: . (repository root)
5. Root directory: repository root

All images are stored in assets/. The site has no npm dependencies.
This ZIP is not the same as the earlier public/ folder layout. Do not mix them.
For a one-file deployment, use the accompanying standalone HTML instead.
